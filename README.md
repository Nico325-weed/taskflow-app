# TaskFlow

Plataforma para gestionar tareas de equipos de trabajo, desarrollada por TechNova.

## Descripción

TaskFlow es una aplicación web que permite a los equipos organizar, asignar y dar seguimiento a sus tareas de manera eficiente.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Instalación

1. Clonar el repositorio
2. Abrir `index.html` en el navegador
